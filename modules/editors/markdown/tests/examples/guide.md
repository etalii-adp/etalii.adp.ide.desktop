# Field guide

A heading-rich document for the markdown editor: the outline above the text
lists every heading here, and clicking one scrolls the editor to its line.

## Reading the preview

The pane beside the text renders what you type, as you type it.

### Emphasis

Text can be *emphasised*, **strong**, or `code`.

## Code fences

```bash
# This line is a shell comment, not a heading - the outline must skip it.
echo "fences are excluded from the outline"
```

## Closing notes

Everything the plain editor guarantees - encoding, line endings, honest
conflict handling - holds here too; the preview and outline are extras.
