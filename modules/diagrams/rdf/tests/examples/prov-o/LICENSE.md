# License: the W3C's document and software terms

`prov-o.ttl` is the namespace document of PROV-O, a W3C Recommendation. Unlike OWL-Time beside
it, the file states no license triple of its own, so the terms come from the specification that
publishes it:

- The PROV-O Recommendation (`https://www.w3.org/TR/prov-o/`) carries the W3C's standard
  notice, linking both the document-use rules
  (`https://www.w3.org/Consortium/Legal/copyright-documents`) and the software notice
  (`https://www.w3.org/Consortium/Legal/copyright-software`). The 2015 combined
  **W3C Software and Document License**
  (`https://www.w3.org/Consortium/Legal/2015/copyright-software-and-document`) is the current
  form of those terms and is the license the owl-diagram specification names as accepted.
- Both the older document terms and the combined license permit copying and redistribution
  with the copyright notice retained. This folder copies the file verbatim and carries the
  notice, which satisfies the stricter reading as well as the newer one — the same position
  this repository's `w3c-turtle` example folder took for the same reason.
