# The Turtle specification's own example

**What it demonstrates.** The smallest real document that exercises the core of the syntax:
`@base` with relative IRIs, prefixes, the `a` keyword, `;` predicate lists, `,` object lists, a
comment, and a language-tagged literal — the example every Turtle author meets first.
