# markdown - examples

- `guide.md` - a heading-rich document: the outline lists its headings, the
  preview renders it, and the code fence inside it proves a `#` in a fence is
  not a heading.

Every readme in this repository is this editor's material too, starting with the
one you are reading now. The module's tests open every file in this folder, so
the examples cannot drift from what the code supports.
