# Two projects

The language repository and this host, at the moment a change to the first was being taken into the second: two projects in the middle of one picture.

**Written for ADP.** No published corpus of agent activity exists, since the notation is new, so nothing here is vendored and no licence but this repository's applies. The names and links are this project's own.

## What it shows

- Two projects, each with its specifications around it, and the layout with more than one centre.
- An agent of one project with a location in a checkout of the other.
- A specification that is finished beside one in progress, and one nobody works on yet.
- A file with no reader's part: nothing is locked, every group is as it comes, and the archived switch is off.

## What it does not demonstrate

- An archived specification, the Input Required status, and environments other than a local machine and a cloud: see `every-state`.
- Locked positions and group states: see `every-state` and `adp-one-day`.
