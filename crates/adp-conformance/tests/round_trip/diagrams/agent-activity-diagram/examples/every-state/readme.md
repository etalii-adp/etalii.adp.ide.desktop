# One of everything

One project with a specification in each status, written to show every state the notation has in one picture.

**Written for ADP.** No published corpus of agent activity exists, since the notation is new, so nothing here is vendored and no licence but this repository's applies. The names are this project's; the situation is made up.

## What it shows

- Every specification status, the archived one included, and the switch set so that it is drawn.
- Every task status, in one specification.
- A specification with two agents, and an agent with two locations.
- A location on `develop` in the folder `Default`, and locations in a worktree, a container path and a home folder.
- Pull requests, two on one location.
- An environment of each kind, one of them shared by two locations.
- A link of each kind: a web page and a project path on an element; a web page and a project path on a task; a web page on a pull request; and a folder link that is a file location, which is shown and not followed.
- A locked element beside unlocked ones, a group unfolded that comes folded, and one folded that comes unfolded.

## What it does not demonstrate

- More than one project: see `two-projects`.
- Anything that breaks a rule, an agent without a specification or a location without an environment: the module's tests hold those.
- A realistic amount of work: see `adp-one-day`.
